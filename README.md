# DevBoard — Kanban Web

SPA en **React 18 + Vite** que consume la API Kanban existente [`kanban-api`](https://github.com/JoacoJust/kanban-api). Frontend del proyecto DevBoard: tableros, columnas y tickets con movimiento optimista, modo claro/oscuro y estética "Minimalismo Developer".

> **Estado del proyecto:** Fase 0 (verificación de especificaciones) ✅ — la implementación avanza por fases según `AGENTS.md` §11, con aprobación humana entre fases.
